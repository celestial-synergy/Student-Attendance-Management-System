# Project Statement

## Project Title
Student Attendance Management System

## Problem Statement

Managing student attendance manually can be time-consuming and may lead to errors in attendance records and percentage calculations. Teachers need a simple system to store student details, record attendance, and generate attendance reports.

The Student Attendance Management System provides a simple Python-based solution for managing student information and attendance records.

## Objectives

- To store student details in an organized manner.
- To record student attendance.
- To calculate attendance percentages automatically.
- To identify students with sufficient or short attendance.
- To generate simple attendance reports.
- To reduce manual calculation and record-keeping errors.

## Scope

The system is designed for basic student attendance management. It allows users to add and view students, search for students, mark attendance, view attendance records, and generate attendance reports.

The project uses Python for implementation and JSON for data storage.

## Functional Requirements

1. The system shall allow users to add student details.
2. The system shall allow users to view the list of students.
3. The system shall allow users to search for a student using the roll number.
4. The system shall allow users to mark attendance as Present or Absent.
5. The system shall calculate attendance percentages.
6. The system shall display attendance reports.
7. The system shall identify students as Eligible or Short Attendance based on attendance percentage.

## Non-Functional Requirements

1. **Usability:** The system should have a simple menu-driven interface.
2. **Performance:** Attendance calculations and reports should be generated quickly.
3. **Reliability:** Student and attendance information should be stored consistently.
4. **Error Handling:** Invalid inputs should be handled appropriately.
5. **Maintainability:** The program should be divided into separate Python modules.
6. **Resource Efficiency:** The system should use minimal memory and processing resources.

## Technologies Used

- Python
- JSON
- Git
- GitHub
- Python unittest

## Expected Outcome

The completed system will provide a simple and organized way to manage student attendance, calculate attendance percentages, and generate attendance reports.
